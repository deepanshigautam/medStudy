# MedStudy

## Overview
MedStudy is a responsive landing page designed for students looking to pursue MBBS abroad. The page provides information about studying MBBS in various countries, the admission process, benefits, and a lead generation form. It is built using **HTML, Tailwind CSS, and JavaScript**, ensuring a clean and optimized user experience.

## Features
- **Responsive Design:** Fully optimized for desktops, tablets, and mobile devices.
- **Hero Section:** Engaging call-to-action with an attractive design.
- **Benefits Section:** Highlights the advantages of studying MBBS abroad.
- **Country Listings:** Provides details of various countries offering MBBS programs.
- **Admission Process:** Step-by-step guide to the application process.
- **Lead Generation Form:** Captures student inquiries with form validation.
- **SEO Optimized:** Structured for better search engine ranking.
- **Performance Tracking:** Integrated with Google Analytics & Facebook Pixel.
- **Fast Loading:** Optimized for speed and efficiency.

## Technologies Used
- **HTML** - Structure of the webpage
- **Tailwind CSS** - Styling and responsiveness
- **JavaScript** - Interactivity and form validation
- **Google Analytics & Facebook Pixel** - Performance tracking
- **Netlify/Vercel** - Deployment
